The proof

Claim. For N ≥ 3 with distinct values, no sequence of rotations turns [1,2,…,N] into [N,…,2,1].

1. Rotation preserves “who follows whom.” On the clock, value v is followed by the same value w before and after any turn, including the wrap from the last slot to the first. So the set of pairs (v → w) never changes. For the original, 1 → 2.

2. The reverse has different pairs. In [N,…,1], the value after 1 is N, and the value after 2 is 1. For N ≥ 3 we have N ≠ 2, so 1 → N ≠ 1 → 2.

3. Conclusion. The pair sets differ, so the reverse is never reachable. Equivalently, there are only N rotations in total, and the table above shows the goal is not among them. ∎

Edge case. For N = 2 we get N = 2, so the pairs match and one rotation does reverse [1,2]. Pick size 2 to see it.
