## How I Practice

1. Try the problem on my own first, usually the brute force.
2. Understand why it is slow or wrong.
3. Improve it step by step to the optimal solution.



## Requirements

- **JDK 21** (LTS): runs most of the solutions in this repo
- **JDK 25** (LTS): required by a few solutions that use newer language features

Check your version with `java -version`.

## Running a Solution

```bash
javac Sorting/BubbleSort.java
java -cp Sorting BubbleSort
```

Replace the path and class name with the file you want to run. Files that declare a `package` need to be run from the project root using the full package name, for example:
```bash
java -cp . Hashing.Chaining.Main
```
